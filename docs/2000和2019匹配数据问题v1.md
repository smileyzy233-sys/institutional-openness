# 2000年与2019年贸易/跨国生产方程变量来源及匹配诊断

## 1. 文档目的

本文档记录贸易成本方程和跨国生产（MP）成本方程在2000年、2019年的变量来源、当前代码中的实际匹配路径、匹配结果及数据质量诊断。

审计对象包括：

- 被解释变量 `value`；
- 核心解释变量 `raw_trade_score`、`raw_mp_score`；
- 协定虚拟变量 `trade_agreement_dummy`；
- 双边政治关系变量 `idealpoint_abs_distance`；
- 关税 `tariff`；
- Gravity数据库中的贸易便利化、文化、社会、法律和历史关系候选变量；
- `matching_diagnostics_2000.csv` 和 `matching_diagnostics_2019.csv` 中记录的缺失、零值与匹配覆盖问题。

审计日期：2026年7月30日。

## 2. 核心结论

2000年和2019年的匹配流程本身均成功完成，没有发现以下致命问题：

- 主键重复；
- 多对多合并导致的行数膨胀；
- 合并后左表观测丢失；
- 被解释变量或核心解释变量错源；
- 协定虚拟变量、政治距离或Gravity候选变量错配；
- 缺失控制变量被错误填为0。

需要区分“匹配阶段直接读取来源”和“变量更上游的原始生成来源”。当前匹配阶段仍然从
`data/processed/trade_dummy_icio_2000_2023.csv`
读取 `raw_trade_score`、`raw_mp_score`、`trade_agreement_dummy`
和 `idealpoint_abs_distance`。其中，`idealpoint_abs_distance`
在更上游由 `ideapoint` 目录中的原始联合国大会理想点数据计算生成，但控制变量匹配阶段不会绕过processed CSV重新读取原始理想点文件。

本轮更新后，`trade_candidate_pool_v1` 共包含49个Gravity候选字段：
45个源字段和4个派生字段。三项已确认的基础控制变量仍然只有
`tariff`、`trade_agreement_dummy` 和 `idealpoint_abs_distance`；
新增Gravity字段均未被自动选入最终回归。

当前最重要的条件性问题包括：

- 2000年所有 `entry_*` 企业开办环境指标均为缺失；
- `rta_coverage` 和 `rta_type` 在本地CEPII CSV中主要随WTO原始RTA记录出现，非RTA国家对大量为空；
- `empire` 在当前76×76目标样本中两年均全部缺失；
- `col_dep_end_year`、`col_dep_end_conflict`、`sever_year`、`sib_conflict`
  是只对特定历史关系有定义的条件型字段，不能把其高缺失率误判为匹配失败。

因此，现有数据适合作为候选池，但不能把49个候选变量机械地一次性组成完整案例回归。

### 3.1 政治距离的两层来源

政治距离的匹配阶段直接来源是：

```text
data/processed/trade_dummy_icio_2000_2023.csv
  └─ idealpoint_abs_distance
```

该列的上游原始来源是：

```text
ideapoint/IdealpointestimatesAll_Jun2024.csv
ideapoint/AgreementScoresAll_Jun2024.csv
```

生成步骤为：

1. 从 `IdealpointestimatesAll_Jun2024.csv` 读取国家、UNGA session和 `IdealPointAll`；
2. 使用 `AgreementScoresAll_Jun2024.csv` 将session映射到年份；
3. 分别匹配来源国和目的国的年度理想点；
4. 计算：

```text
idealpoint_abs_distance = abs(idealpoint_o - idealpoint_d)
```

5. 国内国家对的政治距离设为结构性0；
6. 缺少原始理想点的国际国家对保持缺失，不填0；
7. 将计算结果写入 `trade_dummy_icio_2000_2023.csv`；
8. `match_y_x_cons` 阶段再从该CSV读取并匹配到贸易和MP数据。

因此，“政治距离的原始来源是 `ideapoint` 数据”是正确的，但“当前控制变量匹配阶段已经不再使用processed CSV”是不正确的。

## 4. 当前控制变量选择状态

### 4.1 贸易方程

`trade_candidate_pool_v1` 当前确认的基础控制变量为：

```text
tariff
trade_agreement_dummy
idealpoint_abs_distance
```

以下49个字段已经匹配到数据，但仍属于候选变量，并未被确定为最终回归控制变量。

贸易便利化——成员资格与协定：

```text
gatt_o / gatt_d / both_gatt
wto_o / wto_d / both_wto
eu_o / eu_d / both_eu
fta_wto / fta_wto_raw
rta_coverage / rta_type
```

贸易便利化——企业开办环境：

```text
entry_cost_o / entry_cost_d
entry_proc_o / entry_proc_d
entry_time_o / entry_time_d
entry_tp_o / entry_tp_d
```

文化、社会、法律和历史接近：

```text
gmt_offset_2020_o / gmt_offset_2020_d
comlang_off / comlang_ethno
comrelig / cultural_distance_religion
legal_old_o / legal_old_d / legal_new_o / legal_new_d
comleg_pretrans / comleg_posttrans / transition_legalchange
comcol / col45
heg_o / heg_d
col_dep_ever / col_dep / col_dep_end_year / col_dep_end_conflict
empire / sibling_ever / sibling / sever_year / sib_conflict
scaled_sci_2021 / diplo_disagreement
```

派生候选变量为：

```text
both_gatt = gatt_o * gatt_d
both_wto = wto_o * wto_d
both_eu = eu_o * eu_d
cultural_distance_religion = 1 - comrelig
```

口径上必须注意：

- `entry_*` 衡量企业注册/开办成本、程序和时间，不是海关通关、物流绩效或进出口单证效率；
- `fta_wto` 是WTO数据经Thierry Mayer补充后的RTA指标，`fta_wto_raw` 仅依据WTO原始资料；
- `rta_coverage`、`rta_type`、`legal_old_o/d`、`legal_new_o/d` 和
  `empire` 在CSV中保留CEPII的数值分类编码；
- `gmt_offset_2020_o/d` 是两国各自的2020年时区原始值，不是已经构造好的
  双边时区距离；
- `scaled_sci_2021` 越大表示社会联系越强，但它是2021年固定指标；
- `diplo_disagreement` 越大表示联合国投票立场分歧越大，而不是越接近。

当前流程尚未在贸易便利化和文化指标候选池中确定最终组合，也没有生成
`sample_trade_main`。

`legacy_2019_v1` 曾将 `comlang_off` 和
`cultural_distance_religion` 标记为旧版2019年回归的已选变量，但该配置仅用于旧结果复现，不代表当前研究设定。

## 5. 匹配键、样本与缺失值规则

标准被解释变量主键为：

```text
year + iso_o + iso_d + sector_amne
```

核心解释变量、国家对控制变量和Gravity变量的匹配键为：

```text
year + iso_o_match + iso_d_match
```

关税匹配键为：

```text
year + iso_o1 + iso_d1 + sector_amne
```

其他规则包括：

- 原始 `iso_o`、`iso_d` 保持不变；
- `ROM -> ROU` 只用于 `iso_o_match`、`iso_d_match`；
- 删除涉及 `ROW` 的观测；
- 保留国内流量；
- 国内 `raw_trade_score`、`raw_mp_score`、`trade_agreement_dummy` 为结构性0；
- 国内政治距离为结构性0；
- 关税、国际政治距离和Gravity候选变量缺失不填0；
- 部门20关税保持结构性缺失；
- 所有控制变量均以left join方式并入，不因控制变量缺失删除Y行。
- Gravity大文件使用 `usecols` 和分块读取，先筛选年份、国家存在状态和目标76个经济体；
- 来源国和目的国的单边字段分别保留，不求平均；
- 派生变量仅按配置中的公式计算，并继承基础字段缺失；
- 条件型历史字段的“不适用”缺失与普通数据缺失均保留在匹配层，不自动重编码。

## 8. 各项诊断的原因、严重度与处理建议

### 8.1 关税缺失5%

两年的5%关税缺失均为部门20：

```text
5,776个国家对 × 1个部门 = 5,776行
```

判断：

- 不是匹配错误；
- 不应填0；
- 可以保持现状；
- 加入关税并使用完整案例回归时，部门20会退出估计样本；
- 回归说明中应明确“含关税的设定覆盖部门1—19”。

严重度：低，结构性且符合预期。

### 8.2 双边政治距离缺失

2000年原始理想点缺少：

```text
CHE
HKG
TWN
```

由此形成444个缺失国家对；贸易和2000年MP均有20个部门，因此：

```text
444 × 20 = 8,880行
```

2019年原始理想点缺少：

```text
HKG
TWN
```

由此形成298个缺失国家对：

- 贸易方程：`298 × 20 = 5,960`行；
- MP方程：`298 × 41 = 12,218`行。

判断：

- 不是匹配错误；
- 不应填0；
- 可保持原始缺失；
- 由于政治距离是当前基础控制变量，完整案例估计会排除上述国家相关的国际流量；
- 建议报告样本排除范围，并以“不加入政治距离”的回归作为样本稳健性比较。

严重度：中等、非致命。

### 8.3 2000年 `entry_*` 全缺失

2000年所有 `entry_*` 企业开办环境候选变量均缺失。2019年每个 `entry_*`
变量有1.32%的缺失，具体集中在TWN：

- 来源国字段在 `iso_o_match == TWN` 时缺失；
- 目的国字段在 `iso_d_match == TWN` 时缺失。

判断取决于变量角色：

1. 如果 `entry_*` 继续作为候选变量而不进入正式回归，可以不处理；
2. 如果将其作为正式贸易便利化控制变量，问题是严重的：
   - 2000年完整案例样本将变为0；
   - 2000—2019两期模型会因该变量完全失去2000年观测；
   - 不能把缺失值填0；
   - 应改用有2000年覆盖的贸易便利化指标，或将含 `entry_*` 的扩展设定限制在2003年以后。

严重度：作为候选变量时低；作为正式控制变量时高/致命。

### 8.4 RTA细分字段缺失

`fta_wto` 和 `fta_wto_raw` 两年均完整，但 `rta_coverage` 和
`rta_type` 存在大量缺失：

| 年份 | 缺失国家对 | 缺失贸易行 | 缺失率 |
|---|---:|---:|---:|
| 2000 | 4,522 | 90,440 | 78.29% |
| 2019 | 3,144 | 62,880 | 54.43% |

本地CEPII CSV中，这两个细分字段主要随WTO原始RTA记录出现。
例如，`fta_wto == 1` 但 `fta_wto_raw == 0` 的Thierry Mayer补充协定
通常没有 `rta_coverage` 和 `rta_type`。

判断：

- 合并率和主键均正常，不是匹配失败；
- 匹配层不应把缺失自动填为0；
- 如果模型只需要是否存在RTA，优先使用完整的 `fta_wto` 或 `fta_wto_raw`；
- 如果研究协定覆盖范围或类型，应将分析限制在有相应WTO细分信息的观察，
  并明确条件样本含义；
- `rta_coverage` 和 `rta_type` 是分类编码，不应直接按连续变量解释。

严重度：作为候选字段时低；作为全样本连续控制变量时高。

### 8.5 语言、宗教和法律变量

`comlang_off` 与 `comlang_ethno` 两年均完整，无缺失。

`comrelig` 和派生变量
`cultural_distance_religion = 1 - comrelig`
两年均缺失151个涉及LTU的国家对：

```text
151 × 20 = 3,020行
```

`legal_old_o` 和 `legal_old_d` 分别在CZE作为相应来源国或目的国时缺失，
每列缺失1,520行；`comleg_pretrans` 仅缺失1个国家对、20行。
`legal_new_o/d`、`comleg_posttrans` 和 `transition_legalchange` 无缺失。

判断：

- 这些缺失不是主键匹配错误；
- 共同语言变量不会额外压缩基础控制变量完整样本；
- 宗教距离和整组法律变量的完整案例样本会进一步排除相关国家对；
- `legal_old_o/d`、`legal_new_o/d` 是分类编码，应使用虚拟变量或共同法律渊源指标，
  不应把类别编号当连续数值。

严重度：低，但需要正确处理分类变量。

### 8.6 殖民、依附和共同宗主国字段

`comcol` 和 `col45` 两年均无缺失。`heg_o/d`、`col_dep_ever`、
`col_dep`、`sibling_ever`、`sibling` 每列仅缺失4个国家对。

下列字段只在存在相应历史关系时有定义：

```text
col_dep_end_year
col_dep_end_conflict
sever_year
sib_conflict
empire
```

其缺失率很高，其中 `empire` 在当前76×76样本中两年均全部缺失。

判断：

- 条件型字段的空值多数表示“不适用”，不是一般意义上的缺数；
- 不应直接对其做全样本完整案例控制，否则会将样本压缩到极少数历史关系国家对；
- 如需使用结束年份或冲突信息，应与 `col_dep_ever`、`sibling_ever`
  等适用性虚拟变量联合建模，并先明确“不适用”状态的编码规则；
- `empire` 按当前输出无法作为有变异的控制变量使用。

严重度：作为描述性候选字段时低；机械进入全样本回归时高/致命。

### 8.7 社会联系与外交分歧

`scaled_sci_2021` 的缺失率为：

- 2000年：592个国家对、11,840行，10.25%；
- 2019年：447个国家对、8,940行，7.74%。

`diplo_disagreement` 的缺失率为：

- 2000年：520个国家对、10,400行，9.00%；
- 2019年：374个国家对、7,480行，6.48%。

判断：

- 缺失来自源覆盖，不是匹配失败；
- `scaled_sci_2021` 是固定于2021年的社会联系指标，2000年使用时不能解释为2000年当期社会联系；
- `diplo_disagreement` 数值越大表示政治分歧越大，方向与“接近度”相反；
- 两者进入回归时都会带来非随机的国家对样本缩减。

严重度：中等。

### 8.8 被解释变量零值

零值不是坏数据，而是实际存在的零贸易或零跨国生产流量：

| 年份 | 贸易零值 | 贸易零值率 | MP零值 | MP零值率 |
|---|---:|---:|---:|---:|
| 2000 | 11,487 | 9.94% | 72,014 | 62.34% |
| 2019 | 6,175 | 5.35% | 145,474 | 61.43% |

判断：

- 不是匹配错误；
- 不应在数据清洗阶段删除；
- 如果直接计算 `ln(value)`，所有零值观察都会退出样本；
- MP方程会损失六成以上观察，可能造成严重选择偏差；
- 主估计建议使用原始 `value` 的PPML；
- 仅正值样本的对数OLS可作为稳健性检验，不宜作为主结果。

严重度：匹配层面无问题；若使用对数OLS作为主估计，则方法风险高。

## 10. 可忽略与不可忽略事项

### 10.1 可以保持现状、不需要重新匹配

- 部门20关税结构性缺失；
- 少量政治距离缺失；
- `comrelig` 和文化距离的LTU相关缺失；
- `legal_old_o/d`、`comleg_pretrans` 和少量殖民基础虚拟变量的原始缺失；
- `scaled_sci_2021`、`diplo_disagreement` 的源覆盖缺失；
- 各类 `match_*`、`available_*` 标志本身无缺失；
- 2026年7月30日新构建清单中的Gravity输入SHA256与当前
  `Gravity_V202211.csv` 一致。

上述问题不需要通过填0或重新匹配解决，但需要在估计样本和论文说明中披露。

### 10.2 不能无条件忽略

1. 如果将 `entry_*` 作为正式贸易便利化控制变量，必须改变变量或年份方案；
2. 如果使用 `rta_coverage` 或 `rta_type`，必须明确其条件样本和分类编码，而不能自动补0；
3. 条件型殖民历史字段必须先定义“不适用”状态的建模规则；
4. `empire` 在当前样本中全部缺失，不能直接用于估计；
5. 如果使用 `scaled_sci_2021` 解释2000年结果，必须说明它是2021年固定指标；
6. 如果按理论公式直接对 `value` 取自然对数，必须处理真实零流量造成的大规模样本损失；
7. 如果政治距离作为正式控制变量，需要记录其造成的国家特定样本排除。

## 11. 最终判断

在当前正式配置下：

- 贸易方程使用 `tariff`、`trade_agreement_dummy`、
  `idealpoint_abs_distance`；
- MP方程使用 `trade_agreement_dummy`、
  `idealpoint_abs_distance`；
- Gravity中的49个贸易便利化、文化、社会、法律、殖民和派生字段均为候选变量；
- 4个派生候选变量为 `both_gatt`、`both_wto`、`both_eu` 和
  `cultural_distance_religion`；
- 不对缺失控制变量填0；
- 不生成暗含最终变量选择的 `sample_trade_main`；
- 被解释变量保留零值并建议使用PPML。

按照这一设定，2026年7月30日重建的2000年和2019年匹配结果均可继续用于
候选变量筛选和回归设计，不需要重新进行数据匹配。

下一步不是继续扩充匹配字段，而是基于理论含义、年度覆盖、条件定义、
共线性和样本损失选择最终组合。特别是：

- 若将 `entry_*` 正式加入贸易方程，必须先解决2000年全缺失问题；
- `trade_agreement_dummy`、`fta_wto`、`fta_wto_raw` 和RTA细分字段可能反映
  相近的协定信息，应避免未经检验同时进入同一规格；
- `gatt_o/d`、`wto_o/d`、`eu_o/d` 与对应的 `both_*` 不宜机械地全部同时进入；
- 条件型殖民历史字段和全缺失的 `empire` 不应进入无条件完整案例回归；
- 分类字段应按类别虚拟变量处理，不应把编码值当作连续尺度。
