# 2000年与2019年贸易/跨国生产方程变量来源及匹配诊断

## 1. 文档目的

本文档记录贸易成本方程和跨国生产（MP）成本方程在2000年、2019年的变量来源、当前代码中的实际匹配路径、匹配结果及数据质量诊断。

审计对象包括：

- 被解释变量 `value`；
- 核心解释变量 `raw_trade_score`、`raw_mp_score`；
- 协定虚拟变量 `trade_agreement_dummy`；
- 双边政治关系变量 `idealpoint_abs_distance`；
- 关税 `tariff`；
- Gravity数据库中的贸易便利化和文化指标候选变量；
- `matching_diagnostics_2000.csv` 和 `matching_diagnostics_2019.csv` 中记录的缺失、零值与匹配覆盖问题。

审计日期：2026年7月29日。

## 2. 核心结论

2000年和2019年的匹配流程本身均成功完成，没有发现以下致命问题：

- 主键重复；
- 多对多合并导致的行数膨胀；
- 合并后左表观测丢失；
- 被解释变量或核心解释变量错源；
- 协定虚拟变量、政治距离或Gravity候选变量错配；
- 缺失控制变量被错误填为0。

需要区分“匹配阶段直接读取来源”和“变量更上游的原始生成来源”。当前匹配阶段仍然从
`data/processed/trade_dummy_icio_2000_2023.csv`
读取 `raw_trade_score`、`raw_mp_score`、`trade_agreement_dummy`
和 `idealpoint_abs_distance`。其中，`idealpoint_abs_distance`
在更上游由 `ideapoint` 目录中的原始联合国大会理想点数据计算生成，但控制变量匹配阶段不会绕过processed CSV重新读取原始理想点文件。

当前最重要的条件性问题是：2000年所有 `entry_*` 贸易便利化候选变量均为缺失。如果这些变量不进入正式回归，可以保持现状；如果研究设计坚持将其作为正式控制变量，则2000年样本无法使用这些变量。

## 3. 当前变量来源和匹配路径

| 方程或变量 | 匹配阶段直接来源 | 上游来源或处理 | 当前状态 |
|---|---|---|---|
| 贸易方程 `value` | `Explained_variable/icio{year}.dta` | 直接保留原始值 | 被解释变量 |
| MP方程 `value` | `Explained_variable/amne{year}.dta` | 直接保留原始值 | 被解释变量 |
| `raw_trade_score` | `data/processed/trade_dummy_icio_2000_2023.csv` | 上游由DTA条款编码、权重和生效协定计算 | 贸易核心解释变量 |
| `raw_mp_score` | 同上 | 上游由MP相关DTA条款编码、权重和生效协定计算 | MP核心解释变量 |
| `trade_agreement_dummy` | 同上 | 上游依据 `data/interim/bilateral_panel.csv` 的生效协定构造 | 两个方程的正式控制变量 |
| `idealpoint_abs_distance` | 同上 | 由两国UNGA理想点之差的绝对值计算 | 两个方程的正式控制变量 |
| `tariff` | `control__variable/tariff_2019.csv` 或 `control__variable/tariff2000.dta` | 按年份、来源国、目的国、部门匹配 | 仅用于贸易方程 |
| Gravity候选变量 | `control__variable/Gravity_V202211.csv` | 按国家对—年份匹配 | 仅用于贸易方程候选池 |
| `cultural_distance_religion` | Gravity中的 `comrelig` | `1 - comrelig` | 派生候选变量 |

### 3.1 政治距离的两层来源

政治距离的匹配阶段直接来源是：

```text
data/processed/trade_dummy_icio_2000_2023.csv
  └─ idealpoint_abs_distance
```

该列的上游原始来源是：

```text
ideapoint/IdealpointestimatesAll_Jun2024.csv
ideapoint/AgreementScoresAll_Jun2024.csv
```

生成步骤为：

1. 从 `IdealpointestimatesAll_Jun2024.csv` 读取国家、UNGA session和 `IdealPointAll`；
2. 使用 `AgreementScoresAll_Jun2024.csv` 将session映射到年份；
3. 分别匹配来源国和目的国的年度理想点；
4. 计算：

```text
idealpoint_abs_distance = abs(idealpoint_o - idealpoint_d)
```

5. 国内国家对的政治距离设为结构性0；
6. 缺少原始理想点的国际国家对保持缺失，不填0；
7. 将计算结果写入 `trade_dummy_icio_2000_2023.csv`；
8. `match_y_x_cons` 阶段再从该CSV读取并匹配到贸易和MP数据。

因此，“政治距离的原始来源是 `ideapoint` 数据”是正确的，但“当前控制变量匹配阶段已经不再使用processed CSV”是不正确的。

### 4.1 贸易方程

`trade_candidate_pool_v1` 当前确认的基础控制变量为：

```text

idealpoint_abs_distance
```

以下变量已经匹配到数据，但仍属于候选变量，并未被确定为最终回归控制变量：

其中：

当前新流程尚未在贸易便利化和文化指标候选池中确定最终组合。

`legacy_2019_v1` 曾将 `comlang_off` 和
`cultural_distance_religion` 标记为旧版2019年回归的已选变量，但该配置仅用于旧结果复现，不代表当前研究设定。

### 4.2 MP方程

`mp_controls_v1` 只包括：

```text
trade_agreement_dummy
idealpoint_abs_distance
```

MP方程不会自动加入关税或Gravity贸易候选变量，与原研究设计一致。

## 5. 匹配键、样本与缺失值规则

标准被解释变量主键为：

```text
year + iso_o + iso_d + sector_amne
```

核心解释变量、国家对控制变量和Gravity变量的匹配键为：

```text
year + iso_o_match + iso_d_match
```

关税匹配键为：

```text
year + iso_o1 + iso_d1 + sector_amne
```

其他规则包括：

- 原始 `iso_o`、`iso_d` 保持不变；
- `ROM -> ROU` 只用于 `iso_o_match`、`iso_d_match`；
- 删除涉及 `ROW` 的观测；
- 保留国内流量；
- 国内 `raw_trade_score`、`raw_mp_score`、`trade_agreement_dummy` 为结构性0；
- 国内政治距离为结构性0；
- 关税、国际政治距离和Gravity候选变量缺失不填0；
- 部门20关税保持结构性缺失；
- 所有控制变量均以left join方式并入，不因控制变量缺失删除Y行。

## 6. 2000年逐项核验结果

### 6.1 被解释变量

- 贸易方程：115,520行，与 `icio2000.dta` 逐键比较，`value` 0个差异；
- MP方程：115,520行，与 `amne2000.dta` 逐键比较，`value` 0个差异。

### 6.2 核心解释变量

2000年包含5,776个有向国家对：

- `raw_trade_score`：0个差异；
- `raw_mp_score`：0个差异；
- 国家对—年份主键重复数：0；
- 缺失数：0；
- 国内国家对的raw scores均为0。

### 6.3 国家对控制变量

- `trade_agreement_dummy`：0个差异，覆盖率100%；
- `idealpoint_abs_distance`：与processed CSV逐列一致；
- 国家对控制变量合并率100%；
- 合并前后行数完全一致；
- 右表主键重复数为0。

### 6.4 关税

2000年关税直接来源为：

```text
control__variable/tariff2000.dta
```

核验结果：

- 原始关税国家键为ISO3字符串；
- 匹配前转换为被解释变量使用的数字国家代码；
- 来源国未映射代码为0；
- 目的国未映射代码为0；
- 主键重复数为0；
- 负关税数为0；
- 源文件中的关税值缺失数为0；
- 部门1—19全部覆盖；
- 109,744个目标国家对—部门行的关税值与源文件0个差异；
- 部门20共5,776行没有源数据，保持缺失；
- 源关税文件额外的2,907行全部对应已从回归样本删除的ROW国家对，不是匹配错误。

### 6.5 Gravity变量

2000年筛选后的Gravity数据为76×76＝5,776个有向国家对，主键重复数为0，所有候选字段均与源文件逐列一致。

但2000年以下变量全部缺失：

```text
entry_cost_o / entry_cost_d
entry_proc_o / entry_proc_d
entry_time_o / entry_time_d
entry_tp_o / entry_tp_d
```

检查Gravity原始文件后确认，目标样本中这些变量最早从2003年开始出现非缺失值。因此，2000年全缺失是源数据年份覆盖限制，不是匹配失败。

## 8. 各项诊断的原因、严重度与处理建议

### 8.1 关税缺失5%

两年的5%关税缺失均为部门20：

```text
5,776个国家对 × 1个部门 = 5,776行
```

判断：

- 不是匹配错误；
- 不应填0；
- 可以保持现状；
- 加入关税并使用完整案例回归时，部门20会退出估计样本；
- 回归说明中应明确“含关税的设定覆盖部门1—19”。

严重度：低，结构性且符合预期。

### 8.2 双边政治距离缺失

2000年原始理想点缺少：

```text
CHE
HKG
TWN
```

由此形成444个缺失国家对；贸易和2000年MP均有20个部门，因此：

```text
444 × 20 = 8,880行
```

2019年原始理想点缺少：

```text
HKG
TWN
```

由此形成298个缺失国家对：

- 贸易方程：`298 × 20 = 5,960`行；
- MP方程：`298 × 41 = 12,218`行。

判断：

- 不是匹配错误；
- 不应填0；
- 可保持原始缺失；
- 由于政治距离是当前基础控制变量，完整案例估计会排除上述国家相关的国际流量；
- 建议报告样本排除范围，并以“不加入政治距离”的回归作为样本稳健性比较。

严重度：中等、非致命。

### 8.3 2000年 `entry_*` 全缺失

2000年所有贸易便利化候选变量均缺失。2019年每个 `entry_*`
变量有1.32%的缺失，具体集中在TWN：

- 来源国字段在 `iso_o_match == TWN` 时缺失；
- 目的国字段在 `iso_d_match == TWN` 时缺失。

判断取决于变量角色：

1. 如果 `entry_*` 继续作为候选变量而不进入正式回归，可以不处理；
2. 如果将其作为正式贸易便利化控制变量，问题是严重的：
   - 2000年完整案例样本将变为0；
   - 2000—2019两期模型会因该变量完全失去2000年观测；
   - 不能把缺失值填0；
   - 应改用有2000年覆盖的贸易便利化指标，或将含 `entry_*` 的扩展设定限制在2003年以后。

严重度：作为候选变量时低；作为正式控制变量时高/致命。

### 8.4 文化变量缺失

`comlang_off` 两年均完整，无缺失。

`comrelig` 和派生变量
`cultural_distance_religion = 1 - comrelig`
两年均缺失151个涉及LTU的国家对。贸易数据有20个部门，因此：

```text
151 × 20 = 3,020行
```

判断：

- 不是匹配错误；
- 可以保持缺失；
- 若将文化距离纳入完整案例回归，会排除涉及LTU的观察；
- 缺失率仅2.61%，总体风险较低，但需要在样本说明中披露。

严重度：低。

### 8.5 被解释变量零值

零值不是坏数据，而是实际存在的零贸易或零跨国生产流量：

| 年份 | 贸易零值 | 贸易零值率 | MP零值 | MP零值率 |
|---|---:|---:|---:|---:|
| 2000 | 11,487 | 9.94% | 72,014 | 62.34% |
| 2019 | 6,175 | 5.35% | 145,474 | 61.43% |

判断：

- 不是匹配错误；
- 不应在数据清洗阶段删除；
- 如果直接计算 `ln(value)`，所有零值观察都会退出样本；
- MP方程会损失六成以上观察，可能造成严重选择偏差；
- 主估计建议使用原始 `value` 的PPML；
- 仅正值样本的对数OLS可作为稳健性检验，不宜作为主结果。

严重度：匹配层面无问题；若使用对数OLS作为主估计，则方法风险高。

## 10. 可忽略与不可忽略事项

### 10.1 可以保持现状、不需要重新匹配

- 部门20关税结构性缺失；
- 少量政治距离缺失；
- `comrelig` 和文化距离的LTU相关缺失；
- 各类 `match_*`、`available_*` 标志本身无缺失；
- 2019年构建清单记录的processed CSV哈希早于当前文件版本，但已核验2019年核心字段与当前文件0个差异。

上述问题不需要通过填0或重新匹配解决，但需要在估计样本和论文说明中披露。

### 10.2 不能无条件忽略

1. 如果将 `entry_*` 作为正式贸易便利化控制变量，必须改变变量或年份方案；
2. 如果按理论公式直接对 `value` 取自然对数，必须处理真实零流量造成的大规模样本损失；
3. 如果政治距离作为正式控制变量，需要记录其造成的国家特定样本排除。

## 11. 最终判断

在当前正式配置下：

- 贸易方程使用 `tariff`、`trade_agreement_dummy`、
  `idealpoint_abs_distance`；
- MP方程使用 `trade_agreement_dummy`、
  `idealpoint_abs_distance`；
- Gravity中的 `entry_*`、共同语言和文化距离仍为候选变量；
- 不对缺失控制变量填0；
- 被解释变量保留零值并建议使用PPML。

按照这一设定，2000年和2019年的匹配结果均可继续用于回归，不需要重新进行数据匹配。

如果研究设计进一步决定将贸易便利化指标正式加入贸易方程，则应先解决2000年 `entry_*` 全缺失问题，而不能直接使用当前完整案例样本。
