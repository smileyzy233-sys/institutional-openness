# 贸易与跨国生产命名契约

This contract applies from
`impact_label_schema_version=trade_mp_v1`. The global
`pipeline_schema_version` remains `3.0` so existing Stage 1 gates and manifests
remain valid.

## Channel labels

| Label | Meaning | Fixed weights `(trade, mp)` |
|---|---|---:|
| `trade` | institutional trade-opening channel | `(1.0, 0.0)` |
| `mp` | multinational-production / cross-border-investment channel | `(0.0, 1.0)` |
| `both` | both channels | both weights positive and sum to 1 |
| `none` | neither direct channel | `(0.0, 0.0)` |

`trade_agreement_dummy` keeps its name because it indicates whether a trade
agreement is active. It is not a Stage 2 channel label.

`raw_trade_score` and `raw_mp_score` are the stable downstream explanatory
variable names. `equation="trade"` means the ICIO trade equation;
`equation="mp"` means the AMNE multinational-production equation.

## Historical mapping

Old Stage 2 labels are mapped simultaneously:

```text
{"mp": "trade", "tr": "mp"}
```

The mapping applies only to recognized category fields or structured JSON, not
to arbitrary policy text.

Field renaming includes:

```text
*_investment_weight                   -> *_mp_weight
raw_investment_score                  -> raw_mp_score
effective_investment_weight           -> effective_mp_weight
human_final_investment_weight         -> human_final_mp_weight
both_investment_weight_abs_diff       -> both_mp_weight_abs_diff
*_investment_related_provisions_*     -> *_mp_related_provisions_*
investment_related_provision_coverage -> mp_related_provision_coverage
```

New Stage 2 records carry `impact_label_schema_version=trade_mp_v1` and retain
prompt/source hashes. Migration must preserve row count, key, order, and all
non-naming values. `raw_trade_score` and `raw_mp_score` must remain rowwise
unchanged.
